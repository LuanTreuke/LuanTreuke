## 💻 Sobre mim

<table>
<tr>
<td valign="top" width="62%">

Tô no **6º semestre de ADS no IFPR**, em União da Vitória — já passei da fase de achar que sabia tudo e cheguei na fase de saber que não sei nada. Dizem que é progresso.

Meu terreno favorito é o **back-end**: Java com Spring Boot, TypeScript com NestJS. Mas não fujo do resto — modelo o banco, escrevo a API, monto o front e ainda documento. Sim, eu sou *aquela* pessoa que documenta.

Meu xodó até agora é o **sistema pra floricultura** que virou meu TCC: API, front e documentação em três repositórios que conversam entre si sem brigar.

E olha, diagrama UML e levantamento de requisitos parecem chatos, mas código que ninguém entende depois vira dívida técnica com juros. Prefiro pagar à vista.
